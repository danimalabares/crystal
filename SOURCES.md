# Source guide

This index organizes existing sources; it does not certify that the setup run
has reread the papers or checked their mathematical claims.

## Explanation baseline

- [Dani's explanation requirement](dani-explanations-request.md), copied verbatim
  from the supplied `dani-explanations-requirement.md`.
- [Heap-Project](https://github.com/danimalabares/heap-project). Future mathematical
  work must identify the relevant files and sections actually consulted. No HP
  notes were needed or changed for this file migration.
- Dani's undergraduate thesis is relevant background for wallpaper groups. Its
  exact file was not retrieved or copied in this setup; locate it before citing it.

## Imported source indexes

- [Crystallographic links: sources and provenance](computations/crystallographic-links/SOURCES.md).
  Includes Kaneko–Tokunaga–Yoshida, *Complex crystallographic groups II*;
  Tokunaga–Yoshida, Part I; Morin–Yoshida, the Kühnel triangulation, Part I;
  Arnoux–Marin, Part II; Kühnel–Banchoff; and Bagchi–Datta.
- [Space-group CY3: sources and provenance](computations/space-group-cy3/SOURCES.md).
  Includes Johnson–Burnett–Dunbar, *Crystallographic Topology and Its Applications*;
  [Andreatta–Wiśniewski](https://arxiv.org/abs/0804.4611);
  [Donten-Bury](https://arxiv.org/abs/0812.3758);
  [Burek](https://arxiv.org/abs/2112.03970); and the crystallographic databases.
- [Space-group cached-source manifest](computations/space-group-cy3/sources/MANIFEST.json)
  preserves URLs, sizes, and hashes. The third-party documents themselves were
  not tracked in the source repository and are not included here.

The imported indexes distinguish what their original run read, computed, cited,
or left unchecked. Those labels refer to the original run, not this migration.

## Reading leads for future work

- [Philip Engel, Mumford-construction survey](https://philip-engel.github.io/SurveyMumford.pdf):
  a starting point for the Tate/Mumford learning branch; no theorem is asserted here.
- [Fischer–Ratz–Torrado–Vaudrevange](https://arxiv.org/abs/1209.3906):
  lead for matching affine toroidal actions, not evidence that all 21 are identified.
- [Hashimoto–Kanazawa, Calabi–Yau threefolds of type K (I)](https://arxiv.org/abs/1409.7601):
  definitions and comparison lead; no type-K identification is asserted here.

Private correspondence and meeting transcripts are intentionally not sources
stored in this repository. A research proposal is not a proof.
